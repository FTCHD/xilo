## What you can change

### Controls

| | Values |

| Device Timeout | 0 min, 30 min, 60 min, 120 min, 240 min, 360 min, 720 min, 1440 min |
| Screen Timeout | 20 s, 30 s, 60 s, 300 s, 1800 s |
| Screen Brightness | High, Low, Medium |

### General

| | Values |
| --- | --- |
| Temperature Unit | Celsius, Fahrenheit |

Xilo checks every value against these limits before it sends anything, because the device itself accepts values it can't handle.

## Automations

- **Schedules** can switch Screen at set times, on the days you choose.
- **Alerts** for battery levels and connection.

See [Automations](/docs/automations) for how they work.

## Connection

Xilo talks to the C200(X) with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is A1725.

[Download Xilo](/docs/install) for macOS, Windows or Linux.
