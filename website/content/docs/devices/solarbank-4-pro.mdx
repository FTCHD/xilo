This model has no controls that a schedule can switch. Alerts still work, for battery levels and connection.

## Connection

Xilo talks to the Solarbank 4 Pro with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is AE103.

[Download Xilo](/docs/install) for macOS, Windows or Linux.
