Xilo checks every value against these limits before it sends anything, because the device itself accepts values it can't handle.

## Automations

- **Schedules** can switch AC Output, Car Charger Output, Light, Screen at set times, on the days you choose.
- **Battery reserve** turns outputs off when the battery drops to a level you choose.
- **USB wake** keeps the USB ports on, for devices that turn them off after a while at low load.
- **Alerts** for errors, battery levels, AC power and connection.

See [Automations](/docs/automations) for how they work.

## Connection

Xilo talks to the F1500 with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is A1772.
