Xilo checks every value against these limits before it sends anything, because the device itself accepts values it can't handle.

## Automations

- **Schedules** can switch Car Charger Output, Light and Screen at set times, on the days you choose.
- **Battery reserve** turns outputs off when the battery drops to a level you choose.
- **USB wake** keeps the USB ports on, for devices that turn them off after a while at low load.
- **Alerts** for battery levels and connection.

See [Automations](/docs/automations) for how they work.

## Connection

Xilo talks to the C300 DC with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is A1726.

[Download Xilo](/docs/install) for macOS, Windows or Linux.
