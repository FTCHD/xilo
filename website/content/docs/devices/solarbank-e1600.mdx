This model has no controls that a schedule can switch. Alerts still work, for errors, battery levels and connection.

## Connection

Xilo talks to the Solarbank E1600 with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is A17C0.
