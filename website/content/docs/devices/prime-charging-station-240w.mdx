## What you can change

### Settings

| | Values |
| --- | --- |
| Screen Timeout | 0, 1800, 30, 300, 60 |
| Screen Brightness | High, Low, Medium |
| Charger Usage Mode | High power 1, High power 2, High power 3, Smart dynamic |
| AC 1 Port | On or off |
| AC 2 Port | On or off |
| USB-C 1 Port | On or off |
| USB-C 2 Port | On or off |
| USB-C 3 Port | On or off |
| USB-C 4 Port | On or off |
| Clock Mode | 12h, 24h |
| AC Light Mode | Normal, Sleep |

Xilo checks every value against these limits before it sends anything, because the device itself accepts values it can't handle.

## Automations

This model has no controls that a schedule can switch. Alerts still work: errors, battery levels, AC power and connection.

See [Automations](/docs/automations) for how they work.

## Connection

Xilo talks to the Prime Charging Station 240W with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is A91B2.

[Download Xilo](/docs/install) for macOS, Windows or Linux.
