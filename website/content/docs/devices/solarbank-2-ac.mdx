## What you can change

### Settings

| | Values |
| --- | --- |
| Max Load Parallel | 1200 W, 2400 W, 3600 W, 4800 W |
| Light Mode | Mood, Normal |
| Light | On or off |
| Max Load | 350 W, 600 W, 800 W, 1000 W, 1200 W |
| Disable Grid Export | On or off |
| AC Input Limit | 0 to 1200 W, in steps of 100 W |

### General

| | Values |
| --- | --- |
| Temperature Unit | Celsius, Fahrenheit |

Xilo checks every value against these limits before it sends anything, because the device itself accepts values it can't handle.

## Automations

This model has no controls that a schedule can switch. Alerts still work: errors, battery levels, AC power and connection.

See [Automations](/docs/automations) for how they work.

## Connection

Xilo talks to the Solarbank 2 AC with Anker's ZX Bluetooth protocol, encrypted. It finds the device by itself when you scan, and remembers it. The model number is A17C2.

[Download Xilo](/docs/install) for macOS, Windows or Linux.
