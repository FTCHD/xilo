---
title: Install Xilo
description: Download and install Xilo on macOS, Windows or Linux. The downloads include the app and the xilo command line tool, for Intel, AMD and Arm computers.
---

Download Xilo from the [releases page](https://github.com/ftchd/xilo/releases/latest). Each download contains the app and the `xilo` command line tool.

| System | Download |
| --- | --- |
| macOS, Apple silicon | `Xilo-…-macos-arm64.dmg` |
| macOS, Intel | `Xilo-…-macos-x64.dmg` |
| Windows, x64 | `Xilo-…-windows-x64.zip` |
| Windows, Arm | `Xilo-…-windows-arm64.zip` |
| Debian, Ubuntu | `Xilo-…-linux-x64.deb` or `…-arm64.deb` |
| Fedora, openSUSE | `Xilo-…-linux-x64.rpm` or `…-arm64.rpm` |
| Other Linux | `Xilo-…-linux-x64.tar.gz` or `…-arm64.tar.gz` |

Your computer needs Bluetooth Low Energy. Most computers from the last ten years have it.

## macOS

Xilo needs macOS 13 or newer.

1. Open the disk image and drag **Xilo** to **Applications**.
2. Open Xilo. The download isn't signed by Apple, so macOS warns you the first time. Go to **System Settings → Privacy & Security** and click **Open Anyway**.
3. When macOS asks if Xilo may use Bluetooth, click **Allow**.

To use `xilo` in a terminal, link it once:

```sh
sudo mkdir -p /usr/local/bin
sudo ln -sf /Applications/Xilo.app/Contents/Helpers/xilo /usr/local/bin/xilo
```

## Windows

1. Unpack the zip file, for example into your **Programs** folder.
2. Open **Xilo.exe**. The download isn't signed by Microsoft, so Windows may warn you. Click **More info**, then **Run anyway**.

The `xilo` tool is in the `bin` folder. Add that folder to your `Path` to use it in any terminal.

## Linux

Xilo uses BlueZ for Bluetooth, which most desktop systems include.

<Tabs items={['Debian, Ubuntu', 'Fedora, openSUSE', 'Other']}>
  <Tab value="Debian, Ubuntu">
    ```sh
    sudo apt install ./Xilo-*-linux-x64.deb
    ```
  </Tab>
  <Tab value="Fedora, openSUSE">
    ```sh
    sudo dnf install ./Xilo-*-linux-x64.rpm
    ```
  </Tab>
  <Tab value="Other">
    Unpack the tar.gz file, then run `./Xilo`. To use the command line tool from any folder, link it:

    ```sh
    ln -sf "$PWD/bin/xilo" ~/.local/bin/xilo
    ```
  </Tab>
</Tabs>

The .deb and .rpm packages add Xilo to your app menu and install `xilo` in `/usr/bin`.

Xilo is tested most on macOS. If something doesn't work on Windows or Linux, please [open an issue](https://github.com/ftchd/xilo/issues).
